# 🛡️ AEGIS Portal | Access Control SPA

An ultra-modern, cyberpunk-themed Single Page Application (SPA) designed with Vanilla JavaScript, Tailwind CSS, and GSAP. The application features a reactive multi-state entry form, an encrypted passcode verification gate, maximum attempt enforcement, and responsive glassmorphism UI.

---

## ✨ Features & Key Highlights

- **Cyberpunk / Futuristic Aesthetic**: Styled with a deep dark indigo/black theme (`#0a0a16`), glowing neon borders, ambient grid textures, and dynamic blur overlays.
- **Reactive State 1 (NDA Form)**: Dynamic validation engine ensuring Name, Age ($18+$), valid Email format, and NDA agreement are verified before unlocking submission.
- **Enhanced State 2 (Quantum Passcode Gate)**:
  - 6-digit passcode interface with automatic focus shifting and backspace navigation.
  - Base64 passcode verification (`ODA4ODA4` / Passcode: `808808`).
  - **Max 3 Attempt Lockout**: Enforces security by locking out inputs after 3 consecutive failed attempts.
  - Interactive "Check Passcode" button for manual submission alongside automatic trigger upon entering the 6th digit.
- **Smooth Animations**: Powered by GSAP and ScrollTrigger for entrance stagger, radar pulses, shake error states, and seamless page transitions.
- **Zero-Dependency Core**: Written entirely in pure Vanilla JavaScript and HTML5—no heavy framework required.

---

## 🛠️ Tech Stack

- **HTML5 & Vanilla JavaScript (ES6+)**
- **Tailwind CSS** (via CDN with custom theme extensions)
- **GSAP (GreenSock Animation Platform)** & **ScrollTrigger** (via CDN)

Because the entire application is contained within a single file (`index.html`), setup is instantaneous:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/aegis-portal.git
   cd aegis-portal
   ```

2. **Open in Browser**:
   Double-click `index.html` or run it using a local live server extension (e.g., VS Code Live Server).
